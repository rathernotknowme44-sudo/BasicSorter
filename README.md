## 🔮 WHAT IS THIS?
Standard email clients are blinding, sterile, and built for corporate conformity. **Infinite Void // Gmail** is a custom CSS injection engine that obliterates the blinding white corporate interface of Google Mail, transforming it into a high-end cyber-aesthetic workspace complete with glassmorphic depth, custom telemetry, and Gojo-inspired design geometry.

Built for developers and out-of-the-box thinkers who refuse to stare at flat, boring web apps.

* **Clean DOM Structure:** Lightweight, highly optimized style injections that avoid unnecessary script overhead.

## 🛠️ INSTALLATION GUIDE

To deploy this theme directly to your browser environment:

1. **Clone or Download** this repository as a `.zip` file and extract it to a local folder.
2. Open your browser and navigate to: `chrome://extensions/`
3. Toggle **Developer mode** on in the top-right corner.
4. Click **Load unpacked** in the top-left corner.
5. Select your extracted extension folder.
6. Refresh your `mail.google.com` tab and experience the domain shift.
